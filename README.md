# King Social v6 — Supabase

## التشغيل (5 خطوات)
1. افتح ملف `.env` والصق `SUPABASE_SERVICE_ROLE_KEY` (من Supabase → Project Settings → API Keys). باقي القيم جاهزة.
2. `npm install` ثم `npm start`.
3. ادخل بحساب الأدمن (`ADMIN_USER` / `ADMIN_PASS` من `.env`) وغيّر كلمة المرور.
4. من **الإدارة ← إدارة النظام**:
   - **المفاتيح**: مفتاح Claude، توكن بوت تليجرام (يضبط الويب هوك تلقائياً)، Binance Pay… (لا حاجة لوضعها في .env)
   - **المزودون**: أضف مزود (رابط API + مفتاح) ← «سحب الخدمات + ترجمة».
   - **الإعدادات**: سعر الدولار، نسبة الدعوة، سعر اللوحة الفرعية…
   - **العجلة / المكافآت**: أضف الجوائز التي تريدها.
5. (اختياري) نقل بيانات Firebase القديمة: `FIREBASE_DB=https://xxx.firebaseio.com npm run migrate:firebase`
   (كلمات مرور المستخدمين القديمة تُشفّر أثناء النقل.)

## ⚠️ لا ترفع `.env` على GitHub (موجود في .gitignore). في الاستضافة (Railway...) ضع نفس القيم في Variables.

## اللوحات الفرعية
DNS: سجل Wildcard `*.دومينك ← نفس السيرفر`، وضع `ROOT_DOMAIN=دومينك`، وشهادة SSL Wildcard (Cloudflare).

## آسياسيل (تحويل رصيد)
العميل يدخل رقمه ثم كودين يصلانه من آسياسيل، ويُحوَّل الرصيد إلى رقمك (`ASIA_RECEIVE_NUMBER` من لوحة الأدمن). مفاتيح التطبيق منقولة في `.env`.
⚠️ يعتمد على واجهة تطبيق آسياسيل غير الرسمية: قد يتوقف في أي وقت، وقد يخالف شروط الشركة. جرّبه بمبلغ صغير أولاً.

## TON (تلقائي)
ضع عنوان محفظتك العام في «المفاتيح» (`TON_WALLET_ADDRESS`). السيرفر يراقب الدفعات الواردة ويطابقها بالتعليق. السعر تلقائي من السوق ما لم تحدد «رصيد لكل 1 TON» في الإعدادات.

## البنية
- `server.js` + `lib/` : السيرفر.
- `public/ks-compat.js` : يحاكي Firebase فوق API السيرفر ليعمل `panel.html` القديم.
- `public/ks-v6.js` : تسجيل الدخول الجديد + الصفحات الجديدة + لوحة إدارة النظام + المساعد.
